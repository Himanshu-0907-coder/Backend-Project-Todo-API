# Backend Project

A RESTful Todo API built using Node.js, Express.js, MongoDB, and Mongoose.

## 🚀 Features

- Create a Todo
- Get all Todos
- Get a single Todo
- Update a Todo
- Partially update a Todo
- Delete a Todo

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- Thunder Client
